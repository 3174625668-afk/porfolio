# Moments in Between

Formal project title: **Moments in Between**. Type: **Exhibition Proposal**.
The homepage retains its confirmed project name and existing visual presentation;
its existing entry now opens `projects/moments-in-between/`.

The artist uploaded twelve already-watermarked WebPs (`01.webp`–`12.webp`) to
`public/images/research/exhibition-proposal/pages/`. This existing asset directory
is intentionally retained. No image was moved, recompressed, overwritten or marked
again, and no original PDF is needed. There is no second Exhibition Proposal page.

All pages are 5500 × 2750 spreads, so the shared reader uses its landscape width,
natural 2:1 ratio and continuous vertical reading order. `research-shared/project-data.js`
stores the verified list. The first page loads eagerly and the other eleven lazily.
The unchanged research viewer opens each same original WebP and supports +/−,
wheel/double-click zoom, drag, keyboard access, Escape, touch pinch and exact scroll
restoration. This project's only animation is a one-time, reduced-motion-aware title
entrance. The type label is provided text, not an invented introduction or year.

No other research project records, Art Practice page or gallery design is changed.
